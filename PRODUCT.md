## Platform

## Users
Primário: quem precisa de um sistema sob medida e procura um dev para entregar (pequenas empresas, lojas, clubes e campeonatos, clínicas e profissionais de saúde esportiva, produtores rurais). Chegam pelo link do Wiliam e decidem se vale chamar para orçar.
Secundário: recrutadores e empresas avaliando para vaga de back-end/full-stack, que procuram experiência formal, stack e certificações.

## Product Purpose
Portfólio pessoal de Wiliam Bonetti. Mostra o que já foi entregue e funciona em produção, para gerar contato de freelance; a experiência formal fica visível para quem contrata.

## Positioning
Dev full-stack de produto: entrega o sistema inteiro (back-end, front-end, deploy e IA quando o problema pede), com base sólida de back-end. C# .NET profissionalmente desde 2018 (sistema tributário da SEF/SC), além de Java, Node e Python nos projetos próprios.

## Product Principles
1. Prova antes de promessa: cada projeto mostra o produto real funcionando, com link quando é público.
2. Entregue é entregue: só aparece como entrega o que tem cliente ou está em produção.
3. Sigilo de cliente vale mais que vitrine: projetos privados aparecem sem print e sem nome.
4. Freelance primeiro, carreira visível: o caminho principal é chamar para orçar; a experiência formal sustenta a confiança.
